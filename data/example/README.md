# Example data

Bundled input data for the quick-start example and the illustrative example
(S1-S4). All series cover **2026-01-01 to 2026-06-30** (German market time) at
15-min resolution unless noted otherwise. The files double as format
references for the expected input schemas (see "Input data formats" in the
repository README).

## Provenance

| File(s) | Content | Source |
|---------|---------|--------|
| `prices/prices_DA_example.csv` | Day-ahead auction prices, German bidding zone (DE-LU), 15-min products | market results of EPEX SPOT, retrieved via [Energy-Charts](https://www.energy-charts.info/) (Fraunhofer ISE) |
| `prices/prices_IDC_example.csv` | Continuous intraday index prices (ID3), German bidding zone, 15-min products | market results of EPEX SPOT, retrieved via [Energy-Charts](https://www.energy-charts.info/) (Fraunhofer ISE) |
| `prices/prices_reBAPpos_example.csv`, `prices_reBAPneg_example.csv` | Imbalance settlement prices (reBAP), positive/negative | German TSOs (netztransparenz.de) |
| `prices/prices_FCR_example.xlsx` | FCR capacity auction results (4 h products), unmodified tender-result export | German TSOs (regelleistung.net) |
| `frequency/frequency_example.csv` | Grid frequency of the Continental European synchronous area: 1 Hz measurements aggregated to 15-min statistics, including the normalized FCR droop signal (`FREQ_DROOP_MEAN`) derived per the droop parameters of the example config | German TSOs (netztransparenz.de) |
| `flexibility/vb_bounds_example.csv` | Depot-level virtual-battery flexibility bands (power/energy bounds, reference driving energy) of an electrified truck fleet | generated by the authors: real truck-fleet operating data, synthetically electrified and aggregated into depot-level bands |

Market prices are real, unmodified market outcomes; the only processing
applied to the price CSVs is reformatting to the `time,price` schema and unit
conversion to **EUR/kWh** (divide published EUR/MWh values by 1000).

## Terms of use

These files are included solely to make the bundled examples runnable and to
document the expected input formats. Rights to the underlying market results
remain with their originators (EPEX SPOT SE and the German transmission
system operators). For any use beyond running the bundled examples — in
particular redistribution or commercial use — obtain the data directly from
the original sources under their respective terms.
